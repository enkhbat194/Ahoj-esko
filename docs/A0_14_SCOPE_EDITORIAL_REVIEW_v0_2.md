## Дөрвөн зайлшгүй засвар

1. **Аюулгүй ажиллагаа:** `Pozor!` нь ерөнхий анхааруулга; `Stůj!`/ `Stůjte!` нь зогсох тушаал. `Zastavte stroj!` бол машиныг зогсоох тусдаа нөхцөл. L07 ба L08-ийн үнэлгээний утгыг нийлүүлж болохгүй. Хэлний сургалтын симуляц нь бодит үйлдвэрлэлийн BOZP сургалтыг орлохгүй.
2. **Мэргэжил:** `Pracuji tady.` гэсэн өгүүлбэрээр мэргэжлээ нэрлэсэн гэж тооцохгүй. `Jsem svářeč.` / `Jsem svářečka.` нь нэмж шалгах жишээ, хэлэгчийн хүйстэй тохирсон хэлбэр чухал.
3. **Албан/дотно харилцаа:** `Jak se jmenuješ?` ба `Jak se jmenujete?`-г L10-д өөрийн гэсэн can-do, хоёр сорилтой болгоно. L09 нь харилцааны хэлбэр сонгох; L18 нь нийлэг танилцах сорил.
4. **Хэт том зорилго:** T05-L08 нь санал болгосон уулзалтын цагийг *батлах*; сөрөг санал гаргаж олон алхамтай хэлэлцэх чадвар гэж одоогийн жишээгээр батлах боломжгүй.

## Хөрш хичээлийн зааг

- **T01 L04 → L05 → L06:** тэмдэг/авиа таних → ойролцоо авиаг сонсож ялгах → сонсоод дуурайж хэлэх.
- **T02 L09 → L10 → L18:** ty/vy нөхцөл сонгох → нэр асуух → хосолмол танилцах сорил.
- **T05 L07 → L08:** цаг санал болгох → санал болгосон цагийг батлах.
- **T09 L01/L02/L05/L07/L08:** мэргэжил → багаж нэр → багажийн байршил → зогсох тушаал → ерөнхий/тодорхой анхааруулга.
- **T11 L03 → L04:** хаалга/цонх → бусад гэрийн эд зүйл. Drive-ийн L03-д байсан өргөн “эд зүйл” нь L04-д үлдэх санал, эцсийн шийдвэр биш.
- **T12 L01 → L02:** өнгөний нэрийг *сонсох* → өнгө *нэрлэх*.
- **T13 L03 → L04 → L05 → L07:** хэмжээ асуух → хүссэн хувцас хэлэх → өмсөж үзэх зөвшөөрөл → өөр хэмжээ хүсэх.
