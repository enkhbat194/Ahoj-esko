# Ahoj Česko — A0 сургалтын судалгаанд тулгуурласан шийдвэр v1.0

**Төлөв:** сургалтын архитектурын шийдвэр; батлагдсан клиник/сургалтын үр дүн эсвэл CEFR гэрчилгээ биш.
**Хамрах хүрээ:** A0 = аппын нэршил; CEFR Pre-A1-т ойролцоо бэлтгэл шат; 16 харилцааны сэдэв, 140 **төлөвлөсөн** жижиг хичээл.

## 1. Зөвхөн нэг онолд бүхнийг даатгахгүй

- **Comprehensible input (ойлгомжтой, утгатай сонсох/унших):** сурагчийн танил нөхцөл + зураг, монгол тайлбар, удаан байгалийн чех дуу; шууд урт дүрэм биш. Krashen-ийн `i+1` нь нөлөөтэй таамаглал боловч шинэ агуулгыг яг нэг тоогоор хэмждэг алгоритм гэж үзэхгүй.
- **Output / interaction (өөрөө хэлэх, харилцах):** сурагч эхнээсээ богино асуултад хариулж, өөр нөхцөлд хувирган хэрэглэнэ. Сонсох дангаараа ярих чадварыг батлахгүй.
- **Retrieval practice (санаж гаргаж хэлэх):** орчуулга, текстийг нууж, сурагчийг богино хугацааны дараа өөрөө хариулуулах.
- **Spaced practice (зайтай давталт):** хугацааны зайтай, шинэ сэдвүүд дээр хэрэглүүлэх. Нэг тогтмол 1/3/7 хоногийн хуваарь бүх хүнд хамгийн сайн гэж нотлоогүй тул бодит марталт, оролдлогоор тохируулна.
- **Feedback (алдааны эргэх холбоо):** нэг алдаанд нэг ойлгомжтой богино засвар + дахин хэлэх оролдлого. Бүх дүрмийн хүснэгтийг урьдчилан заахгүй.
- **Cognitive load (танин мэдэхүйн ачаалал):** нэг шинэ чадвар, 4–6 хэллэг/үг орчим зорилтот жижиг багц (хичээлийн туршилтаар тохируулах); заавал тогтмол тоо биш.
- **Transfer (шинэ нөхцөлд хэрэглэх):** `Děkuji`-г танилцахад үзвэл кафе, ажил, эмнэлэгт өөр хүнтэй дахин хэрэглүүлнэ.

## 2. Хичээл бүрийн хөдөлгүүр

Бодит зорилго → утгатай богино харилцан яриаг сонсох → ойлгосныг шалгах → утгатай хэсгээр давтах → тусламжийг багасгах → санаж хэлэх → хувьчилсан өгүүлбэр → 2–6 ээлжийн яриа → огт хараагүй нөхцөлд зорилго биелүүлэх → алдаа засах + зайтай давтлага.

Сонссон өчүүхэн хэллэгийг дуудах, илүү том өгүүлбэр бүтээх боломж олгоно; чех үг бүрийг механикаар үеэр таслахгүй. Урт/богино эгшиг, эхний үеийн өргөлт, Ř, Č/Š/Ž зэрэг ялгааг шаардлагатай мөчид чиглүүлнэ.

## 3. Үнэлгээний үнэн зөв байдал

- **Task success:** бодит зорилго биелсэн эсэх.
- **Comprehension:** эсрэг талын асуултыг ойлгосон эсэх.
- **Appropriateness:** чи/та, албан/дотно хэллэг тохирсон эсэх.
- **Intelligibility:** сонсогч ойлгохуйц дуудсан эсэх; төгс аялга шаардахгүй.
- **Repair strategy:** ойлгоогүйдээ давтан хэлүүлэх, өөр үгээр асуух чадвар.
- **Retention:** 7 ба 30 хоногийн дараа шинэ өгүүлбэр/нөхцөлд санаж хэрэглэж буй эсэх.

**STT ≠ дуудлагын үнэлгээ.** ASR нэг үгийг зөв текст болгосон нь зөв дуудсан баталгаа биш; буруу текст болгосон нь сурагч алдаа гаргасан гэсэн баталгаа биш. Нэр, 15/50 гэх төстэй тоо, шуугиан, монгол аялгатай сурагчдыг тусгай тестлэнэ. Алдааны эргэлзээтэй үед буруу оноо тавихгүй, дахин сонсох боломж өгнө.

**Progress (ахиц):** зөвхөн нийтэлсэн агуулгад тулгуурласан төгссөн хичээл, бие даан хэлсэн зорилго, бодит идэвхтэй суралцсан минут, давтлагын үр дүнг үзүүлнэ; 140 төлөвлөсөн гарчиг 140 сурсан хичээл биш.

## 4. Судалгаагаар баталгаажуулахаас өмнө хэлж болохгүй зүйлс

- “10 дахин хурдан сургана”; “хэзээ ч мартахгүй”; “80% нь CEFR-ийн албан оноо”; “AI дуудлагыг 100% зөв үнэлдэг” гэсэн баталгааг ашиглахгүй.
- `i+1`-ийг хүний тархины хэмжигдсэн шууд оролтын оноо гэж үзэхгүй.
- Нэр, хэлний хүндэтгэлийн хувилбар, `Prosím`-ийн олон утгыг үгчилсэн нэг орчуулгаар хувиргахгүй.
- Аудио байхгүй бол бүтэн ажиллаж байна гэж тэмдэглэхгүй. Бодит Чех редакц, Монгол хэлний редакц, автомат QA, суралцагчийн туршилтын статус тусдаа байх ёстой.

## 5. Баталгаажуулах туршилтын загвар

1. Эхлээд A0-T02 мэндчилгээний 18 жижиг хичээлийн **зөвхөн хэдэн бодит хичээл** дээр ажиллагаатай audio + хариулт + сорил бүтээнэ.
2. Чех эх хэлтний контентын засвар, Монгол утгын засвар, хүний аудио сонсголын үнэлгээг контентын редакцад тусдаа тэмдэглэнэ. Хэрэглэгчээс QA хийхийг шаардахгүй.
3. Жижиг pilot-д сурагчдын 1-р оролдлого, тусламж хэрэглэсэн эсэх, шинэ нөхцөлийн даалгавар, 7/30 хоногийн сэргээн санах үр дүнг (зөвшөөрөлтэй) хэмжинэ.
4. Давтлагын хуваарь, дасгалын тоо, хурдны тохиргоог энэ өгөгдөлд үндэслэн өөрчилнө.
5. Баталгаажуулсны дараа хөтөлбөрийн бусад сэдэв рүү өргөтгөнө.
