# AHOJ — Design system (working requirements)
2026-11-25. Existing orange/charcoal app and research05 palette are references, neither final. Owner wants modern, adult, attractive and low-friction UI. Do not produce a separate app or screenshot-only UI.
## Core UX
One clear task per active screen, one primary action, consistent progress/back/resume, safe-area spacing, 48–56px touch targets as design target; check WCAG 2.2 contrast/focus. Keep main navigation on main views only; hide five-tab bar during focused exercises. No duplicate menus, excessive badges, decorative clutter or childish game visuals. Use typography and restrained color to guide attention; actual color tokens to be selected in working app preview, not assumed final.
Group related learn/listen items when helpful. Immediate choice feedback without redundant Check taps; clear correction then continue. Avoid forcing typing in speaking tasks. Provide replay, listen-first dialogue with transcript optionally revealed, speech attempt and clear unavailable-mic path; separate assisted from independent success. No fake waveforms labeled as live audio analysis or fake pronunciation scores.
## Component pool
Letter/sound introduction, word/chunk card, listen/repeat, sound discrimination, listen-to-meaning, match, contextual choice, gap fill, model-order tiles, independent spoken recall, dialogue, transfer, explicit literacy/dictation, review. Add components only for a pedagogical requirement. Reusable semantic HTML/CSS/JS, responsive layout, accessible controls; pictures only to clarify meaning, never cut UI screenshots into buttons. Every exercise gets audio role/status and grading mode from data.
## Evidence
Use actual browser screens and interactions, 320/390/430px layout smoke tests, genuine iPhone Safari where available, no horizontal overflow, no unreachable primary controls. User reference recordings and OctoLearn research are interaction examples, not proof of effectiveness and not a mandate to copy English phonics or a competitor's assets. Preserve reader's guided current-word interaction. Final UI remains subject to learner evidence and owner review.
